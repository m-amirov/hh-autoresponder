# hh-autoresponder — бот авто-откликов на вакансии hh.ru

Телеграм-бот, который сам ищет вакансии на **hh.ru**, отбирает подходящие и
откликается за тебя. Работает в фоне, управляется через Telegram, шлёт подробный
лог действий. Всё настраивается через `.env` — код трогать не нужно.

> ⚠️ **Дисклеймер.** Авто-отклики нарушают правила hh.ru. Аккаунт могут
> ограничить. Используй на свой риск и держи разумные лимиты. Проект — для
> личного использования.

---

## Что умеет

- 🔍 Каждые 5 минут ищет вакансии на hh.ru по твоим запросам (с пагинацией)
- 🎯 Оценивает каждую вакансию по правилам (заголовок, зарплата, стек, уровень) — без трат токенов
- 📨 Сам откликается через официальный API hh, ровным человеческим темпом
- ✉️ Отправляет твоё сопроводительное письмо (одно на всех, задаётся в конфиге)
- 🧠 Опционально: если у вакансии тест/анкета — на вопросы отвечает ИИ (нужен LLM-ключ)
- ⏱ Антибан: случайные паузы между откликами, дневной лимит
- 💬 Ловит сообщения рекрутёров и присылает тебе в Telegram
- 📊 Тянет статусы откликов (приглашения / отказы / без ответа)
- ⬆️ Поднимает резюме в поиске
- 📱 Управление через меню бота: пауза, вкл/выкл откликов, статистика, логи

---

## Требования

- **Python 3.12+**
- Аккаунт на **hh.ru** с опубликованным резюме
- Телеграм-бот (токен из [@BotFather](https://t.me/BotFather))
- (опционально) ключ LLM-провайдера — только если нужно, чтобы ИИ проходил тесты работодателя

База — SQLite (файл), ничего дополнительно ставить не нужно.

## Установка

```bash
git clone https://github.com/YAMAKAYAMACO/hh-autoresponder.git
cd hh-autoresponder

python -m venv .venv
# Windows:
.venv\Scripts\pip install -e .
.venv\Scripts\playwright install chromium
# macOS/Linux:
# .venv/bin/pip install -e .
# .venv/bin/playwright install chromium

cp .env.example .env      # затем открой .env и заполни
```

## Настройка (`.env`)

Обязательный минимум:

| Поле | Что это |
|---|---|
| `TG_BOT_TOKEN` | токен бота из [@BotFather](https://t.me/BotFather) |
| `TG_ADMIN_CHAT_ID` | твой числовой id из [@userinfobot](https://t.me/userinfobot) |
| `HH_LOGIN` / `HH_PASSWORD` | почта/телефон и пароль от hh.ru |

Дальше подгони под себя (уже с адекватными дефолтами):

- `SEARCH_QUERIES_RAW` — поисковые запросы через запятую
- `COVER_LETTER` — текст сопроводительного письма (уходит всем)
- `TARGET_KEYWORDS_RAW` / `NEGATIVE_KEYWORDS_RAW` / `STACK_KEYWORDS_RAW` — правила отбора вакансий
- `DESIRED_SALARY_MIN` / `MAX`, `SALARY_FLOOR` — зарплатные ориентиры
- `APPLY_DELAY_MIN` / `MAX`, `MAX_APPLIES_PER_DAY_HH` — темп и лимит откликов

Резюме (нужно только при `AI_ENABLED=true`): скопируй `configs/resume.example.txt`
в `configs/resume.txt` и впиши свои данные.

### ИИ — по желанию

По умолчанию `AI_ENABLED=false` — бот откликается без всякого ИИ. Если хочешь,
чтобы ИИ отвечал на анкеты/тесты работодателя, поставь `AI_ENABLED=true` и укажи
`LLM_API_KEY` (любой OpenAI-совместимый провайдер, по умолчанию — polza.ai).

## Первый вход на hh (один раз)

```bash
.venv\Scripts\python manual_login.py     # Windows
# .venv/bin/python manual_login.py       # macOS/Linux
```

Откроется окно браузера — залогинься на hh руками (телефон/почта + пароль, при
необходимости SMS). Скрипт сам поймает вход и сохранит сессию в
`data/browser_sessions/`. После этого отклики работают сами.

---

## Запуск

```bash
.venv\Scripts\python -m app.main     # Windows
# .venv/bin/python -m app.main       # macOS/Linux
```

Дальше всё управление — через меню твоего бота в Telegram. Пока процесс запущен —
бот работает. Автозапуск при старте системы настраивается штатными средствами ОС
(Планировщик задач / автозагрузка / systemd).

---

## Как это работает

```
поиск (hh, каждые 5 мин)
        │
        ▼
отбор по правилам (rule-based скоринг, без токенов)
        │
        ▼
отклик через официальный API hh + фиксированное письмо
        │
        ├─ если у вакансии тест/анкета → Playwright (+ ИИ, если включён)
        ▼
лог в Telegram + сводка по откликам
```
